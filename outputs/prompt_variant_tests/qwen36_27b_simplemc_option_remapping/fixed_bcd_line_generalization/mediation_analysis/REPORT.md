# Fixed-B/C/D selected-line semantic transfer and mediation

## Bottom line

On both frozen splits, replacing the selected-line ordinary-attention history
moves Neutral strongly toward the donor semantic answer at B, C, and D, but it
does not move Game reliably toward that answer. A later same-pipeline fixed-A
calibration shows the same pattern at A, so the old two-mapping fixed-A Game
effect was design-contingent rather than a genuine position exception.
Blocking the matching repeated line
removes only a modest part of Neutral's transfer, and a matched-length
nonmatching-line blockade removes more. Therefore the B--D donor effect is not
uniquely mediated by the matching repeated option.

See the [same-pipeline fixed-A calibration](../../fixed_a_full24_calibration/analysis/REPORT.md)
for the resolved A comparison.

This is compatible with the separate natural-history lesion showing that
actual candidate-to-matching-candidate relays causally govern preferential
Game switching. The interventions answer different questions: the natural
lesion removes the model's real matching evidence; this transplant asks
whether a counterfactual semantic history can replace it. Neutral accepts that
replacement, while Game largely does not.
